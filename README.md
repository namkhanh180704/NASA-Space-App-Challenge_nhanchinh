# 🚀 7 Minutes of Terror

A space survival game that runs right in your browser. Your ship is plunging toward a
planet's surface, and you have **7 minutes** to keep it in one piece until touchdown.

## 🎮 Gameplay
- Pick a **planet** (Moon / Mars) and a **difficulty**.
- Run between the ship's rooms and deal with emergencies as they happen:
  - 🔥 **Fires**: grab an extinguisher from a red rack and put them out (supplies are limited).
  - ⚡ **Short circuits**: cut the burnt wires and reconnect them at the junction box before spraying.
  - 💨 **Hull breaches**: carry a patch from a grey rack and weld the hole before the oxygen runs out.
  - ☄️ **Asteroid storms**: get to the defense turret in the control room and shoot them down.
  - 🌡️ **Engine overheating**: above 1,300 °C the engine fails and the ship falls faster.
- Complete mini-tasks: rotate pipes, match signal waves, tighten bolts, memorize light
  sequences, match cards, answer quizzes and more.
- Final phase: choose a flat landing site and fire the braking engine to touch down
  at **under 3 m/s**.

## 👥 Multiplayer
- One player hosts a room and shares the **room code** with up to **3 friends**.
- No account needed. Players connect peer-to-peer via PeerJS.
- The number of incidents, ship size and medkit uses scale with the number of players.

## ✨ Features
- 4-page interactive tutorial for new players
- **English / Vietnamese** language support
- Customizable key bindings, saved on your device
- Sound effects, ship map and an incident log after every round

## ▶️ How to Play
1. Download the `.html` file and open it in any modern browser (Chrome, Edge, Firefox…), **or**
2. Play online via GitHub Pages: `https://<your-username>.github.io/<repo-name>/`

## 🛠️ Built With
HTML5 Canvas · Vanilla JavaScript · Web Audio API · PeerJS (multiplayer) · localStorage
