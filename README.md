# NASA-Space-App-Challenge_nhanchinh
7 Minutes of Terror: a browser survival game where you fix failures, fight fires and land your spacecraft safely on the Moon or Mars. Play solo or with up to 4 players using a room code. One HTML file, no install needed.. Chơi một mình hoặc tối đa 4 người qua mã phòng. Chỉ cần một file HTML, không phải cài đặt.
